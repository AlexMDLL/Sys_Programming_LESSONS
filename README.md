# Пара 17. Хуки Windows и события клавиатуры

Стартовый проект: Windows Forms-приложение, которое сначала ловит клавиши обычным событием `KeyDown`, а дальше — низкоуровневым hook (`WH_KEYBOARD_LL`).

## Структура

```
HooksCourse/
├── HooksCourse.sln
├── KeyboardHookLab/            — winforms, net9.0-windows
│   ├── Program.cs              — точка входа, цикл сообщений
│   └── MainForm.cs             — окно с журналом клавиш
└── t/Пара 17. Хуки Windows и события клавиатуры.md
```

Каталог `KeyboardHookLab/Interop` появится в П2, там будет обёртка над `SetWindowsHookEx`.

Запуск:

```
dotnet build
dotnet run --project KeyboardHookLab
```

## П1

1. Обработчик `KeyUp` рядом с `KeyDown`.
2. Нажатие и отпускание пишутся отдельными строками.
3. `Escape` очищает журнал.
4. Проверить, что при переключении в другое приложение события не идут.
5. Объяснить разницу `KeyPreview` и системного hook.

Сделано: `KeyDown` и `KeyUp` пишут строки `[KeyDown] <клавиша>` и `[KeyUp] <клавиша>`, модификаторы в скобках (`A (Alt)`). `Escape` чистит журнал и оставляет отметку `[System] Журнал очищен (Esc)`.

Пример журнала:

```
[KeyDown] A
[KeyUp] A
[KeyDown] B
[KeyUp] B
[KeyDown] ShiftKey
[KeyUp] ShiftKey
[System] Журнал очищен (Esc)
```

Проверка:

| Действие | Ожидаемый результат |
|---|---|
| Нажать `A` | `[KeyDown] A`, затем `[KeyUp] A` |
| Нажать `Shift` | `[KeyDown] ShiftKey`, затем `[KeyUp] ShiftKey` |
| `Alt+A` | `[KeyDown] A (Alt)`, модификатор видно в скобках |
| `Esc` | журнал пуст, одна строка `[System] Журнал очищен (Esc)` |
| Уйти в Блокнот и печатать там | новых строк нет |
| Вернуться | события снова пишутся |

### `KeyPreview` vs hook

`KeyPreview` — свойство формы WinForms. Оно только меняет порядок доставки: `WM_KEYDOWN` сначала получает форма, потом контрол с фокусом. Событие всё равно приходит в наше окно, т.е. работает только пока окно активно.

Hook — механизм самой Windows (`WH_KEYBOARD_LL`). Callback вызывается системой на всё, что нажимается в системе, независимо от того, какое окно в фокусе. Поэтому в П2, чтобы не собирать чужие нажатия, hook и ставится только на время активности окна.
