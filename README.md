# Вариант 14. Менеджер ресурсов

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** GC, IDisposable, using, FileStream, SafeHandle

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Создать класс, который владеет FileStream.
2. Реализовать запись и чтение данных.
3. Реализовать IDisposable и защиту от использования после Dispose.
4. Проверить повторный вызов Dispose.
5. Использовать using и проверить закрытие при исключении.
6. Объяснить разницу между управляемой памятью и внешним ресурсом.
7. Снять показатели GC.GetTotalMemory и CollectionCount без принудительного GC.

## Дополнительные задания
8. Добавить IAsyncDisposable, если используемый ресурс поддерживает асинхронное освобождение.
9. Реализовать тесты на владение потоком и leaveOpen.
10. Описать, почему GC.Collect не заменяет Dispose.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
