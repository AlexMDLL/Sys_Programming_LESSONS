Цель: создать небольшой диспетчер, который запускает разрешённую утилиту и сообщает, как она завершилась.
Создание проекта

В Visual Studio 2022:

    Создайте Console App.
    Назовите проект Practice1_ProcessManager.
    Выберите .NET 9.

Проверка результата

При успешном запуске студент должен увидеть примерно такой результат:

PID: 12345
Длительность: 00:00:01.2345678
Exit code: 0

PID и длительность будут различаться на разных компьютерах.

Затем проведите два теста:

    Успешный: dotnet --info запускается и завершается.
    Ошибочный: временно замените FileName на заведомо несуществующее имя, например missing-tool-12345.exe.

Ожидаемый результат второго теста — обработанное сообщение об ошибке запуска, а не аварийное завершение приложения.
