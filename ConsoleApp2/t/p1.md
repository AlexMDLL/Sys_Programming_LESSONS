
# П1

Цель: обработать один набор заказов двумя способами, сравнить длительность и увидеть, что порядок завершения работы не гарантирован.

### Создание проекта

В Visual Studio 2022:

1. Создайте `Console App`.
2. Назовите проект `Practice1_ThreadOrders`.
3. Выберите .NET 9.
4. Замените `Program.cs` стартовым кодом ниже.

```
        Order[] orders =

            new(1, 100),
            new(2, 200),

        // TODO 2. Создайте массив Thread размером orders.Length.

        // TODO 3. Для каждого заказа создайте поток,
        // который вызывает pocOrda для этого заказа.

        // TODO 4. Запустите все созданные потоки.

        // TODO 5. Дождитесь завершения каждого потока

```

### Ожидаемый результат

Последовательная обработка восьми заказов занимает приблизительно 800 мс плюс накладные расходы.

Многопоточная версия может завершиться быстрее, поскольку несколько задержек могут перекрываться. Однако конкретное время зависит от системы и нагрузки.

Пример структуры вывода:

```
=== Последовательная обработка ===
Заказ 1: поток 1
Заказ 1 завершён. Сумма: 105.00
...
Время: около 00:00:00.800

=== Многопоточная обработка ===
Заказ 1: поток 12
Заказ 2: поток 13
...
Время: зависит от системы
```

Числа потоков и порядок сообщений будут другими.

### Граничный сценарий

Запустить программу с одним заказом. Сравните результаты: при очень маленьком объёме работы накладные расходы на создание потоков могут оказаться больше потенциальной выгоды.
